# Temat 11. Wyjaśnienia do praktyki

## Wyrażenie składane

[wyrazenie for element in dane if warunek] tworzy nową listę. Wyrażenie przekształca wybrany element, końcowe if filtruje. Umiej rozwinąć zapis do zwykłej pętli.

## Nowy słownik

{klucz: wartosc for element in dane} tworzy słownik. Przy powtórzonym kluczu pozostaje ostatnia obliczona wartość. To inna reguła niż dodawanie liczników.

## enumerate

enumerate(dane, start=0) udostępnia pary numer-element. start=1 zmienia numerowanie raportu, a nie indeksy w oryginalnej liście. Rozpakuj parę w nagłówku pętli.

## zip

zip(a, b) łączy elementy z odpowiadających pozycji. Domyślnie kończy na krótszym wejściu. Jeśli wszystkie rekordy muszą mieć partnera, najpierw sprawdź zgodność długości.

## Oddzielenie obliczenia

Funkcja analizy zwraca kolekcję lub bool. Program główny nadaje etykiety i kolejność wydruku. Walidację formatu wykonuj przed dostępem do konkretnych cyfr kodu.
