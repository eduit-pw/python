# Startery: temat 41

Każdy starter odpowiada jednemu zadaniu. Pełne polecenia i oczekiwane wyniki są w [README lekcji](../README.md).

Skopiuj wybrany plik do folderu lekcji, aby pliki danych pozostały obok programu. Jeśli zadanie ma własny folder, skopiuj cały folder i wykonuj w nim polecenia. Zachowaj własną wersję poprzedniego etapu.

`NotImplementedError` lub komentarz TODO oznacza pracę do wykonania. Sam import albo uruchomienie pustego okna nie potwierdza ukończenia zadania. W szkieletach funkcji dodaj własne wywołania i próby.

| Zadanie | Starter | Uruchomienie |
| --- | --- | --- |
| 1. Funkcja Cezara | [zadanie1.py](zadanie1.py) | `python zadanie1.py` po uzupełnieniu |
| 2. Testy jednostkowe | [zadanie2.py](zadanie2.py) | `python zadanie2.py` po uzupełnieniu |
| 3. Szyfr z par | [zadanie3.py](zadanie3.py) | `python zadanie3.py` po uzupełnieniu |
| 4. Dla chętnych: Sprawdzenie odwracalności | [zadanie4.py](zadanie4.py) | `python zadanie4.py` po uzupełnieniu |

**Moduł pomocniczy:** skopiuj także [cezar.py](cezar.py) obok rozwiązania i uzupełniaj go w zadaniach, które go dotyczą. Nie importuj kodu z folderu nauczyciela.

Testy zadania 2: `python -m unittest zadanie2 -v` albo `python zadanie2.py` po skopiowaniu pliku i modułu cezar.py obok siebie.
