# Konstrukcje do powtórzenia

| Zapis | Zastosowanie |
| --- | --- |
| `from logika import funkcja` | Wykorzystanie logiki z osobnego modułu. |
| `return wynik` | Oddanie wyniku obliczenia. |
| `except ValueError as blad` | Obsługa błędnej wartości. |
| `clicked.connect(self.oblicz)` | Reakcja na kliknięcie. |
| `value()` i `isChecked()` | Odczyt pól GUI. |
| `setText(str(wynik))` | Pokazanie wyniku. |
| `assertEqual(...)` i `assertRaises(...)` | Sprawdzenie wyniku i wyjątku. |
| `python -m unittest -v` | Uruchomienie testów. |
