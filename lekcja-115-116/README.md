# Temat 58. II próba: konsola, Django i Git

**Lekcje:** 115-116. **Czas pracy:** 90 minut. **Maksymalnie:** 20 punktów.

Zakres: konsola, prosty formularz Django, Git i komentarze. Konkretne polecenie otrzymasz na zajęciach. Przygotuj się przez samodzielne uruchomienie wcześniejszych ćwiczeń na nowych danych.

## Co umieć przed próbą

- Oddzielić obliczenie od pobierania danych i wyświetlania wyniku.
- Importować tę samą funkcję do dwóch sposobów obsługi programu.
- Sprawdzić poprawny wynik, zero i błędne dane.
- Uruchomić oddawaną kopię oraz opisać, jak działa.

Przed II próbą wróć do tematów 27, 37 i 54–57. Powtórz forms.Form, GET/POST, cleaned_data, CSRF, wynik 0 i lokalne commity. FastAPI nie należy do zakresu tej próby.
