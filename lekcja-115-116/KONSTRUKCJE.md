# Konstrukcje do powtórzenia

| Zapis | Zastosowanie |
| --- | --- |
| `from logika import funkcja` | Wykorzystanie logiki z osobnego modułu. |
| `return wynik` | Oddanie wyniku obliczenia. |
| `except ValueError as blad` | Obsługa błędnej wartości. |
| `forms.IntegerField(min_value=0)` | Liczbowe pole formularza. |
| `form.is_valid()` | Sprawdzenie przesłanych danych. |
| `form.cleaned_data["pole"]` | Odczyt poprawnie sprawdzonej wartości. |
| `{% csrf_token %}` | Token w formularzu POST. |
| `{% if wynik is not None %}` | Pokazanie także wyniku 0. |
| `git status`, `git diff`, `git add`, `git commit` | Sprawdzenie i zapis rzeczywistego etapu pracy. |
