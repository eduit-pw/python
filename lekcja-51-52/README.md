# Temat 26. Projekt programistyczny

**Lekcje:** 51-52. **Czas:** 90 minut.

Polecenie, dane i sposób sprawdzenia przekaże nauczyciel na zajęciach. Przygotuj działające środowisko i powtórz wcześniejsze ćwiczenia. Po uruchomieniu sprawdź poprawne dane, przypadek graniczny i błąd.

Projekt obiektowy realizujecie w zespołach 2–3-osobowych. Każda osoba pisze kod oraz co najmniej jeden test i wyjaśnia swój fragment. Całość oddajecie jako jeden skrypt z sekcjami oddzielonymi komentarzami.
