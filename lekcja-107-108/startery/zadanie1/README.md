# Zadanie 1: Django

Pełne wymagania są w README lekcji. To fragmenty do własnego projektu Django, a nie samodzielne skrypty do polecenia python zadanie.py.

W aktywnym venv wykonaj `python -m pip install "Django~=5.2.0"`, `django-admin startproject szkola .`, `python manage.py startapp strony`, `python manage.py migrate` i `python manage.py runserver`. Pracuj w nowym folderze roboczym.
