# Startery: temat 66

Każdy starter odpowiada jednemu zadaniu. Pełne polecenia i oczekiwane wyniki są w [README lekcji](../README.md).

Skopiuj wybrany plik do folderu lekcji, aby pliki danych pozostały obok programu. Jeśli zadanie ma własny folder, skopiuj cały folder i wykonuj w nim polecenia. Zachowaj własną wersję poprzedniego etapu.

`NotImplementedError` lub komentarz TODO oznacza pracę do wykonania. Sam import albo uruchomienie pustego okna nie potwierdza ukończenia zadania. W szkieletach funkcji dodaj własne wywołania i próby.

| Zadanie | Starter | Uruchomienie |
| --- | --- | --- |
| 1. Raport z lokalnego API | [zadanie1.py](zadanie1.py) | `python zadanie1.py` po uzupełnieniu |
| 2. Filtr query | [zadanie2.py](zadanie2.py) | `python zadanie2.py` po uzupełnieniu |
| 3. Próby błędne | [zadanie3.py](zadanie3.py) | `python zadanie3.py` po uzupełnieniu |
| 4. Dla chętnych: Integracja demonstracyjna AI | [zadanie4.py](zadanie4.py) | `python zadanie4.py` po uzupełnieniu |

Skopiuj także serwer.py i requirements.txt do folderu lekcji. Zainstaluj zależności. W pierwszym terminalu: `python -m uvicorn serwer:app --reload`. Klienta uruchamiaj w drugim terminalu. API_TOKEN dotyczy lokalnej demonstracji, nie prawdziwego dostawcy AI.
