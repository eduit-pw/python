# Startery: temat 69

Każdy starter odpowiada jednemu zadaniu. Pełne polecenia i oczekiwane wyniki są w [README lekcji](../README.md).

Skopiuj wybrany plik do folderu lekcji, aby pliki danych pozostały obok programu. Jeśli zadanie ma własny folder, skopiuj cały folder i wykonuj w nim polecenia. Zachowaj własną wersję poprzedniego etapu.

`NotImplementedError` lub komentarz TODO oznacza pracę do wykonania. Sam import albo uruchomienie pustego okna nie potwierdza ukończenia zadania. W szkieletach funkcji dodaj własne wywołania i próby.

| Zadanie | Starter | Uruchomienie |
| --- | --- | --- |
| 1. Raport z progiem | [zadanie1.py](zadanie1.py) | `python zadanie1.py` po uzupełnieniu |
| 2. Pomoc i błędne argumenty | [zadanie2.py](zadanie2.py) | `python zadanie2.py` po uzupełnieniu |
| 3. Błąd danych wejściowych | [zadanie3.py](zadanie3.py) | `python zadanie3.py` po uzupełnieniu |
| 4. Dla chętnych: Priorytet konfiguracji | [zadanie4.py](zadanie4.py) | `python zadanie4.py` po uzupełnieniu |

Skopiuj dane.json z folderu lekcji. Dla zadania 4 zainstaluj python-dotenv i przygotuj własny plik .env obok skryptu.

Zależność do tych starterów: `python -m pip install python-dotenv`.
