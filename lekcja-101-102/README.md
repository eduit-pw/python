# Temat 51. Projekt programistyczny

**Lekcje:** 101-102. **Czas:** 90 minut.

Polecenie, dane i sposób sprawdzenia przekaże nauczyciel na zajęciach. Przygotuj działające środowisko i powtórz wcześniejsze ćwiczenia. Po uruchomieniu sprawdź poprawne dane, przypadek graniczny i błąd.

Powtórz kontrolki PyQt, odczyt danych z formularza, obsługę błędów i użycie funkcji bazy SQLite. Obowiązkowy zakres mieści się w jednym bloku.
